PDF Tools

PDF의 각 페이지 외곽에 여백을 추가합니다. (페이지 크기가 커지고, 기존 콘텐츠는 중앙에 배치됩니다.)

2개의 페이지를 가로로 나란히 붙여 한 페이지로 만듭니다. (새 페이지 너비는 두 페이지의 합, 높이는 둘 중 큰 값입니다.)

여러 이미지를 하나의 PDF로 만듭니다. (각 페이지는 해당 이미지 크기에 맞춰 생성됩니다.)

    여러 PDF 파일을 순서대로 이어붙여 하나의 PDF로 만듭니다. (각 페이지의 원래 크기는 그대로 유지됩니다.)

      PDF의 각 페이지를 이미지로 변환해 ZIP 파일로 내려받습니다.
